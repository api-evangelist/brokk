# Brokk

> Brokk (Brokk, Inc.) builds AI tooling for large codebases. It ships open-source developer tools — not a hosted REST API — centered on "bifrost", a Tree-sitter-backed multi-language static-analysis engine that gives coding agents structured code intelligence (symbols, definitions, references, call graphs, usage analysis) across 12 languages, exposed as a CLI, a language server (LSP), and a stdio MCP server. Founded by Jonathan Ellis (Apache Cassandra / DataStax). Backed by Mayfield.

This llms.txt was generated by the API Evangelist enrichment pipeline from the Brokk apis.yml profile and the repository artifacts; Brokk does not publish its own llms.txt.

## Products

- [Brokk](https://github.com/BrokkAi/brokk): The core application — brings code intelligence to AI (Java, GPL-3.0).
- [bifrost](https://github.com/BrokkAi/bifrost): Multi-language static analysis for agents, editors, and large repositories (Rust). CLI + LSP + MCP.
- [brokk-cli](https://github.com/BrokkAi/brokk-cli): Launcher for the Brokk Java executor, ACP, and the Bifrost MCP server.
- [mjolnir](https://github.com/BrokkAi/mjolnir): Terminal client for Agent Client Protocol (ACP) servers (Rust).
- [anvil](https://github.com/BrokkAi/anvil): ACP server using OpenRouter, Codex, and/or Ollama (Rust).

## Agent access (MCP)

- [Bifrost MCP server](https://brokkai.github.io/bifrost/mcp/): Stdio MCP server started with `bifrost --root /path/to/project --mcp "symbol|extended"`. Exposes toolsets for symbol search, code query, workspace management, text search, git analysis, and SlopCop code-quality metrics. Tool catalog: mcp/brokk-mcp.yml.
